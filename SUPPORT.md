# Support Guide

Welcome to the AgroMarket Support Guide! We want to make sure you get the help you need, whether you are a buyer, seller, developer, or node operator.

## 🔍 Search Existing Resources

Before asking a question, please check the following:
1. **GitHub Issues:** Search our [GitHub Issues](https://github.com/agromarket/agromarket/issues) to see if someone else has already reported the issue or asked the same question.
2. **Project README:** Check the [README.md](README.md) for installation, dependencies, and configuration steps.
3. **Walkthrough Docs:** Read the [walkthrough.md](walkthrough.md) for explanations of specific features like Stellar payments, RLS, and reviews.

## 💬 Community Channels

- **Discord Community:** Join our chat rooms at [Discord.gg/agromarket](https://discord.gg/agromarket) for general discussions, troubleshooting, and collaboration.
- **Stellar Developer Forum:** For developer-related questions about Horizon nodes, Stellar SDK, and testnet payment configurations, check out [stellar.org/developers](https://stellar.org).

## 🐛 Reporting Bugs

If you've verified the bug exists:
1. Open a new [GitHub Issue](https://github.com/agromarket/agromarket/issues/new).
2. Fill out the bug template completely.
3. Include your environment (Node.js version, browser, OS) and step-by-step reproduction instructions.
4. Attach screenshots or terminal error logs if applicable.
