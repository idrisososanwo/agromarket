# Security Policy

## Supported Versions

We actively provide security updates for the following versions of AgroMarket:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of our decentralized marketplace, Stellar wallet integrations, and Supabase database integrity very seriously. If you discover a security vulnerability, please do **not** open a public GitHub issue. Instead, report it privately:

1. Email a detailed vulnerability report to `security@agromarket.org`.
2. Include steps to reproduce the issue, proof of concept (PoC), and potential impacts.
3. We will acknowledge receipt of your report within 48 hours and coordinate a fix.

## Our Pledge

We pledge to:
- Respond to your report in a timely manner.
- Coordinate a timeline for patching the issue.
- Provide public credit/recognition to reporters once the issue has been resolved and published, if desired.

Please practice responsible disclosure and give us reasonable time to patch vulnerabilities before disclosing them publicly.
